# Personal Finance Tracker

A MySQL project focused on personal finance management.  
Built to strengthen SQL skills through real-world schema design, 
queries, and data analysis.

## Goals
- Design a normalized database schema
- Practice complex SQL queries (joins, aggregations, CTEs, window functions)
- Write and optimize stored procedures

## Tech Stack
- MySQL

## Structure
- `schema/` — table definitions
- `queries/` — practice queries
- `data/` — sample data
