# 💰 Personal Finance Tracker

A MySQL project focused on personal finance management.  
Built to strengthen SQL skills through real-world schema design, 
queries, and data analysis.

## 🎯 Goals
- Design a normalized database schema
- Practice complex SQL queries (joins, aggregations, CTEs, window functions)
- Write and optimize stored procedures

## 🛠️ Tech Stack
- MySQL

## 📂 Structure
- `schema/` — table definitions
- `data/` — sample data
- `queries/01_joins_and_aggregations.sql` — JOINs, GROUP BY, HAVING
- `queries/02_ctes.sql` — Common Table Expressions
- `queries/03_window_functions.sql` — SUM OVER, ROW_NUMBER, LAG, LEAD
- `queries/04_stored_procedures.sql` — reusable procedures with parameters
- `queries/05_optimization.sql` — EXPLAIN, indexes

## 📚 Concepts Covered
- Schema design & normalization
- JOINS (INNER, multiple tables)
- Aggregations (SUM, GROUP BY, HAVING)
- CTEs & chained CTEs
- Window Functions (SUM OVER, ROW_NUMBER, LAG, LEAD)
- Stored Procedures with IN parameters
- Query optimization with EXPLAIN & indexes
